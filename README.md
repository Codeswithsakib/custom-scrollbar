# custom-scrollbar
link: https://codeswithsakib.github.io/custom-scrollbar/custom-scrollbar
1. WHAT THE PROJECT DOES?
This project creates a custom-designed scrollbar for a webpage using CSS. Instead of the default browser scrollbar, it changes the color, width, and hover behavior to match a dark-themed UI.
2. TOOLS/LANGUAGE USED?
html5 and css3
3. STEPS TO BUILD AND RUN?
Open code editor VS Code
Create a file named index.html
Did html and css codes
Save the file
Open it in any web browser (Chrome, Firefox, Edge)
upload to github
4. KEY FEATURES/ANY CHALLENGES?
Transparent color effects using opacity (#7775, #5555)
difficulties using webkit
